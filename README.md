# 🍑 Cute Timer

브라우저 하나로 돌아가는 뽀모도로 타이머. 설치 없음, 의존성 없음, 파일 하나.

## 실행

```bat
run.bat
```

Edge(없으면 Chrome)를 앱 모드로 띄웁니다. 또는 `index.html`을 그냥 브라우저에서 열어도 됩니다.

## 사용법

- **시작 / 일시정지**: 가운데 버튼
- **시간 설정**: 5분 · 10분 · 25분 버튼, 또는 다이얼을 드래그 (1분 단위, 최대 60분)
- 집중(25분) → 휴식(5분) 반복, 4번째 집중 후에는 긴 휴식(15분)
- 시간이 끝나면 삐 소리 3번 후 자동으로 다음 단계로 넘어갑니다

## 파일

| 파일 | 역할 |
|---|---|
| `index.html` | 타이머 전체 (HTML + CSS + JS) |
| `run.bat` | 앱 창으로 실행하는 Windows 스크립트 |
| `timer.ico` | 아이콘 |
